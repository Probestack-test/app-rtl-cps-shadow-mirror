# Observability User Guide

This service was generated with observability enabled because `frameworkOptions.observability=true` was selected.

Selected options:

- Health Checks
- Metrics
- Prometheus Endpoint
- Distributed Tracing

The generated observability setup uses Spring Boot Actuator and Micrometer. It is intentionally lightweight: no custom observability Java classes are generated by default.

## Runtime Configuration

```properties
app.observability.enabled=true
# Enabled actuator endpoints.
management.endpoints.web.exposure.include=health,info,loggers,metrics,prometheus
# Health, readiness, and liveness probes.
management.endpoint.health.probes.enabled=true
management.endpoint.health.show-details=never
# Common Micrometer metric tags.
management.metrics.tags.application=${spring.application.name}
# Distributed tracing.
management.tracing.enabled=true
management.tracing.sampling.probability=0.1
```

## Local Verification

Start the generated service and verify enabled endpoints:

```bash
curl http://localhost:8080/actuator/health
curl http://localhost:8080/actuator/health/liveness
curl http://localhost:8080/actuator/health/readiness
curl http://localhost:8080/actuator/metrics
curl http://localhost:8080/actuator/prometheus
```

## Distributed Tracing

Distributed tracing is enabled with Micrometer tracing. The generated default samples 10% of requests:

```properties
management.tracing.enabled=true
management.tracing.sampling.probability=${MANAGEMENT_TRACING_SAMPLING_PROBABILITY:0.1}
```

Override `MANAGEMENT_TRACING_SAMPLING_PROBABILITY` per environment. Use a tracing collector/exporter compatible with the generated Micrometer tracing dependencies.


## Cloud Run Health Checks

When health checks are enabled, use the liveness endpoint for deployment verification:

```bash
curl -f ${SERVICE_URL}/actuator/health/liveness
```

This verifies the HTTP process is reachable without requiring every downstream dependency to be production-ready during scaffold testing.

## Prometheus

When the Prometheus endpoint is enabled, a Prometheus-compatible collector can scrape:

```text
/actuator/prometheus
```

The generated service exposes the endpoint only when `prometheusEndpoint=true`.
